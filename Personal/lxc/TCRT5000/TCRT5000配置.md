# TCRT5000配置

## 接线

| 引脚号 | TCRT5000编号 | 说明                               |
| ------ | ------------ | ---------------------------------- |
| 3.3V   | VCC          | \                                  |
| GND    | GND          | \                                  |
| PA1    | D0           | 数字识别                           |
| PA0    | A0           | 模拟识别，本实验精度要求不高不需要 |

## CUBEMX配置

（不包含A0，如果需要的配置ADC1的IN0就可以了）

## keil配置

```c
if (HAL_GPIO_ReadPin(TCRT_GPIO_Port, TCRT_Pin) == GPIO_PIN_RESET)
		{
			
			// 引脚读到低电平，说明检测到物体/白线
		}
		else
		{

			// 引脚读到高电平，说明没检测到/黑线
		}
```

根据需要把代码写进这个if else里面就行了，示例里这里面控制的是F1自带LED的亮灭
