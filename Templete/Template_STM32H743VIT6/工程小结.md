
## 2. 硬件资源总表

### 2.1 时钟

- SYSCLK = HCLK = 240MHz；APB1 = APB2 = 120MHz（DIV2）；电源 Scale0，Flash latency 4
- **H7 规则：APB 分频≠1 时定时器内核时钟 = 2×APB → 所有定时器内核 = 240MHz**
- 定时器频率 = 240M / PSC / ARR（本工程 PSC、ARR 均已按此配置验证）

### 2.2 定时器

| 定时器 | 用途 | 配置 | 频率/周期 |
|--------|------|------|-----------|
| TIM1 | 舵机 PWM ×4（CH1-4: PE9/PE11/PE13/PE14） | PSC=2400-1, ARR=2000-1 | **50Hz**，1 tick=10µs |
| TIM8 | 舵机 PWM ×2（CH3-4: PC8/PC9） | 同上 | **50Hz** |
| TIM4 | 电机 PWM ×2（CH1=PD12 电机A, CH2=PD13 电机B） | PSC=12-1, ARR=1000-1 | 20kHz，比较值 0~1000 |
| TIM2 | 电机A编码器（PA0/PA1） | 编码器模式 TI12，32位 | 4 倍频 |
| TIM3 | 电机B编码器（PA6/PA7） | 编码器模式 TI12，16位 | 4 倍频 |
| TIM16 | 系统 20ms 节拍（IT） | 优先级 0 | 20ms |
| TIM17 | 系统 1ms 节拍（IT） | 优先级 0 | 1ms |
| TIM7 | 微秒延时 `Delay_Us(n)`（AT24C02 软件 I2C 用） | PSC=240-1 → 1MHz 计数 | 1µs/tick |

### 2.3 串口与 DMA（2026-08-14 状态）

| 串口 | 引脚 | 现状 | 用途 |
|------|------|------|------|
| USART1 | PA9/PA10 | **DMA 收发**（RX=DMA1_Stream0, TX=DMA1_Stream1，NORMAL/Byte） | 调试打印、VOFA 上位机调参（Menu_Param/Con_Task 均打这里） |
| USART2 | PA2/PA3 | 中断收 + 阻塞发（DMA 待 CubeMX 加） | 预留 |
| USART3 | PB10/PB11 | 中断收 + 阻塞发（DMA 待 CubeMX 加） | 预留 |
| UART4 | PA11/PA12 | 中断收 + 阻塞发（DMA 待 CubeMX 加） | **TJC 串口屏**（TJC_LCD_SERIAL = Serial4） |

> ★ 串口层已做**自动 DMA 适配**（见 §6.4）：给任意串口在 CubeMX 加 DMA 并重新生成后，代码自动走 DMA + 缓存维护，**无需再改任何代码**。

### 2.4 I2C 与存储

- **I2C1**（PB6/PB7，硬件 I2C，轮询）：挂 IMU（MPU6050 / ICM42688，地址 0x68）
- **AT24C02**（软件 I2C：PA4=SCL, PA5=SDA，用 `Delay_Us`/TIM7 延时）：参数持久化（模式记忆、IMU 零偏等）

### 2.5 引脚总表

| 功能 | 引脚 | 说明 |
|------|------|------|
| LED0 | PA8 | LED 状态灯（Flash_Mode） |
| KEY0 | PE3 | 单击=切换下一个模式（Mode_G） |
| KEY1 | PC0 | 调参/菜单导航 |
| KEY2 | PC1 | |
| KEY3 | （Key.h 定义 KEY_COUNT=4，物理引脚见 main.h） | |
| EC11 旋钮 | PC4(S1)/PC5(S2)，下降沿 EXTI | 调参滚轮 |
| EC11 按键 | PB0 | |
| OLED（软件I2C） | PB8=SCL, PB9=SDA | |
| 电机A | PD12=PWM(TIM4_CH1), PD10=方向GPIO | 编码器 PA0/PA1 |
| 电机B | PD13=PWM(TIM4_CH2), PD11=方向GPIO | 编码器 PA6/PA7 |
| 舵机1-4 | PE9/PE11/PE13/PE14 | TIM1 CH1-4 |
| 舵机5-6 | PC8/PC9 | TIM8 CH3/4 |

### 2.6 MPU / Cache（H7 关键）

| Region | 地址 | 属性 |
|--------|------|------|
| 0 | 0x24000000 512KB（D1 AXI SRAM，全局变量默认区） | **CACHEABLE + BUFFERABLE** |
| 1 | 0x30000000 128KB（D2 SRAM） | 不可缓存 |
| 2-4 | 0x30020000 / 0x30040000(32KB) / 0x38000000(64KB) | 不可缓存 |

I-Cache 与 D-Cache 均已开启。**凡 DMA 缓冲放在普通全局变量区，必须做缓存维护**（串口层已内置，见 §6.4/§9）。

## 3. 系统运行骨架（Top + Mode）

### 3.1 启动流程

```
main.c: MPU_Config → SCB_EnableICache/DCache → HAL_Init → SystemClock_Config
        → MX_GPIO → MX_DMA → MX_USART1 → MX_TIM2/3/16/17/7 → MX_USART2 → MX_TIM1/4/8
        → MX_I2C1 → MX_UART4 → MX_USART3 → Mymain()
```

`Mymain()` 调 `Mode_G_Setup()`：
1. `Initial_ALL()`（**顺序不可调换**）：
   - Hardware：`OLED_Init()` → `IMU_Mahony_Init(0)` → `Con_Servo_Init()`（6 路归中 90°）
   - Software：`Serial_Init()` → `Encoder_Init()`（EC11 EXTI）
   - Control：`Con_Motor_Init()` → `Param_AT24C02_Init()`（★电机 PID 先于 EEPROM 恢复，否则被默认值覆盖）
   - Tools：`Flash_Mode_Init()` → `Timer_Counter_Init()`
2. `Initial_Timer()`（★必须最后，防止开局访问空指针）→ 启动 1ms/20ms 中断
3. 从 AT24C02 恢复上次模式：`next_mode = 恢复值; curr_mode = Mode_Null` → 触发完整模式切换（Setup）

### 3.2 Mode 状态机机制

- 全局变量：`curr_mode`（当前）、`next_mode`（目标），类型 `Mode_Typedef`（`Mode_Null, Mode_1..6, Mode_End`）
- 每轮主循环：`curr==next` → 跑 `Mode_X_Loop()`；不等 → 先 `Mode_X_Exit()`（旧）再 `Mode_X_Setup()`（新），然后 `curr=next`
- **模式变化时写一次 AT24C02**（static last_saved 去重，不会每轮都写）
- 切换 API：`Mode_To_Next()`（KEY0 单击触发，顺移一位，到 Mode_End 回绕 Mode_Null）、`Mode_ChangeTo(mode)`
- 每个 Mode 有 4 个函数：`Setup / Loop / Tick(20ms中断) / Exit`
- ⚠️ 不要在 Mode 内部直接改 `curr_mode`，只改 `next_mode`

### 3.3 各 Mode 现状

| Mode | 现状 | 内容 |
|------|------|------|
| Mode_G | ✅ 全局 | 常驻：按键切模式、OLED 显示、1ms/20ms 回调、模式记忆 |
| Mode_1 | ✅ 脱机调参 | ParamEdit 参数编辑器（OLED+EC11+按键），注册 7 个参数：`curr_mode`、IMU 陀螺/加速度零偏 6 个；参数与 AT24C02 联动保存 |
| Mode_2 | ✅ 实验 | 按键/LCD 交互示例：KEY1 或屏按键→Serial1 打印、yaw 20ms 打印、LCD 参数显示 |
| Mode_3 | ✅ 菜单任务 | Menu_Task 调参菜单（Menu_Param，KEY_1 导航 + Con_Task 执行 9 个调参任务）；Exit 恢复角度环 |
| Mode_4/5/6 | 空骨架 | 仅 OLED 显示 `===Mode_X===`，待填充业务 |

### 3.4 中断节拍链

- **1ms（TIM17）**：`Key_Tick()`（按键扫描）→ `Flash_Mode_Tick()`（LED 闪烁）
- **20ms（TIM16）**：`IMU_Mahony_Update_Tick()`（姿态解算）→ `Con_Task_Tick()`（任务分发）→ `Mode_X_Tick()` → `Motor_Speed_Update_Tick(20)`（电机速度环）
- 弱函数机制：MyTimer.c 定义 `__attribute__((weak)) Timer_1ms_Callback/Timer_20ms_Callback`，**Mode_G.c 强定义覆盖**；用户可再覆盖

### 5.4 Servo（舵机，180°，6 路）

```c
typedef struct { MyPWM_Typedef *Servo_PWM;
                 uint16_t pwm_min, pwm_max;      // 0°/180° 对应比较值（50/250 tick）
                 uint16_t pos_min, pos_max;      // 角度限幅
                 int16_t current_pos; } Servo_Typedef;
```

- 生命周期：`Setup(一次) → Run(每帧) → IsExit?→true → 自动出队下一个`；`.Tick` 在 20ms 中断分发

### 6.4 Serial_porting（Function/Serial_porting.h/c）★核心

```c
typedef struct {
    USART_TypeDef *Instance; UART_HandleTypeDef *huart;
    uint8_t rxBuf[800] __attribute__((aligned(32)));   // 接收缓冲（773→补齐整 cache line）
    uint8_t txBuf[256] __attribute__((aligned(32)));   // DMA 发送缓冲
    uint16_t rxLen;
    Serial_ABC_Data_Typedef ABC_Data; Serial_HEX_Data_Typedef HEX_Data;
} Serial_Typedef;
extern Serial_Typedef Serial1(USART1), Serial2(USART2), Serial3(USART3), Serial4(UART4);
```
- 初始化：`Serial_Init()`（4 路自动按 DMA 句柄选择接收模式）
- **自动 DMA 适配**（本工程特有设计）：
  - 接收：`Serial_StartRx()` — `huart->hdmarx != NULL` → `HAL_UARTEx_ReceiveToIdle_DMA`，否则 `_IT`
  - 发送：`Serial_TX()` — `huart->hdmatx != NULL` 且 len≤256 → `HAL_UART_Transmit_DMA`，否则阻塞发送
  - 回调 `HAL_UARTEx_RxEventCallback`：DMA 串口解析前 `SCB_InvalidateDCache_by_Addr(rxBuf)`，重启走统一 `Serial_StartRx`
  - ⇒ **CubeMX 给哪个串口加 DMA，哪个串口就自动用 DMA，代码零改动**
- **防死锁丢帧设计**：DMA 完成中断与 TIM 中断同为抢占优先级 0，无法互相抢占。`Serial_TX` 在中断上下文（`__get_IPSR()!=0`）里若 TX 忙 → **直接丢弃本帧**；主循环上下文才允许 `while(gState==BUSY_TX)` 等待
- 发送 API（内部均走 Serial_TX，调用方零感知）：`Serial_printf(pSerial, fmt, ...)`、`Serial_send_string`、`Serial_SendBytes`、`Serial_Send_HEX_Package`
- 接收 API：`Serial_GetNewPackageFlag_ABC/HEX`、`Serial_GetHexData(index)`、`Serial_GetHexLen`、`Serial_SetFloatData/SetIntData`、`Serial_Check_Str/CheckCmd`、`Serial_GetError_ABC/HEX`、`Serial_Clear_ABC`、`Serial_PrintDebug`

### 6.5 Menu_Param（Function/Menu_Param.h，Mode_3 使用）

- 调参任务菜单：`TuneTaskID` 枚举（`TUNE_GYRO_CAL, TUNE_GYRO_YAW, TUNE_MOTOR_A_SPEED/ANGLE/POS, TUNE_MOTOR_B_SPEED/ANGLE/POS, TUNE_CAR_STRAIGHT, TUNE_COUNT`）
- 按键：KEY_1 单击=下一项、长按=入队/再次长按=Skip；OLED 显示菜单
- API：`Menu_Tune_Init() / Menu_Tune_Loop() / Menu_Tune_Cursor()`；任务表 `Menu_Tune_Table[TUNE_COUNT]`

| 层 | 文件 | 职责 |
|----|------|------|
| 驱动 | `bsp_at24c02.h/c` | 软件 I2C（PA4/PA5）+ TIM7 微秒延时；`AT24C02_Init/WriteByte/ReadByte`；`AT24C02_USE_SW_I2C` 宏可切硬件 I2C |

## 9. 串口协议细节

### ABC 协议（上位机/VOFA 调参、串口屏指令）

```
[@][DATA...][$][#]     帧头'@'  帧尾'$#'
```
用途：`Serial_SetFloatData(pSerial, "关键字", "格式串", &变量)` 提取参数；TJC 屏也走 ABC 帧。

### HEX 协议（设备间通信，带校验）

```
[0xFF][0xAA][LEN][D1_H][D1_L][D1_CK][D2_H][D2_L][D2_CK]...[DN_H][DN_L][DN_CK][0x55][0xFE]
```
- **LEN = 字个数**（1 个字 = 1 个 int16_t = 高字节+低字节+校验共 3 字节）
- 每字校验 `D_CK = D_H ^ D_L`；**单字校验失败该位置保留原值**
- 完整帧最小字节数 `needed_len = 2 + 1 + LEN*3 + 2`；帧尾位置 `tail_idx = 3 + LEN*3`
- 接收用 `Serial_GetHexData(pSerial, index)` / `Serial_GetHexLen`；发送用 `Serial_Send_HEX_Package(pSerial, data[], count)`

### DMA 与 D-Cache 设计（H7 特有，改串口前必读）

1. 全局变量区（0x24000000）可缓存，DMA 直写内存绕过缓存：
   - TX：填好 `txBuf` 后 `SCB_CleanDCache_by_Addr` 再启动 DMA
   - RX：解析前 `SCB_InvalidateDCache_by_Addr(rxBuf)`
2. `rxBuf/txBuf` 均 32 字节对齐且补齐整 cache line，保证缓存操作不误伤结构体相邻字段
3. 所有中断优先级 0 → 中断上下文里 TX 忙直接丢帧（防死锁），主循环才等待
4. 帧长 >256 字节（HEX 大包）自动回退阻塞发送

## 10. 关键坑与约定（必读）

1. **舵机 PWM 必须是 50Hz**：比较值 50~250 tick（0.5~2.5ms），90°=150。旧代码注释里的 2000/500 是错误残留（5~20ms 会打满周期烧舵机）。`Servo_Init` 有 50Hz 死循环校验兜底。
2. **Initial_ALL 顺序不可调**：`Con_Motor_Init` 必须先于 `Param_AT24C02_Init`（否则 EEPROM 恢复的 PID 被默认值覆盖）；`Initial_Timer` 必须最后（防开局访问空指针）。
3. **CubeMX 重新生成**：会覆盖 Core/ 文件（USER CODE 区保留），dma.c/h、MspInit 等由 CubeMX 管理；新增 .c 文件由用户自行加入 Keil 工程。
4. **中断里禁止阻塞等待**：所有 IRQ 抢占优先级 0。在 ISR 里等 DMA/其他中断完成 = 死锁。串口层已内置丢帧保护，新代码同样遵循。
5. **AT24C02 布局**：参数表顺序不可改，只许末尾追加；`PARAM_FORCE` 用完必须注释。
6. **Con_Task 枚举顺序不可改**（任务参数持久化依赖）。
7. **IMU 二选一**：宏 `IMU_USE_MPU6050` 控制，两个芯片同 I2C 地址，不能同挂。
8. **编码**：全工程 UTF-8（Buzzer.c 是 GBK 残留空壳，蜂鸣器未移植）。
9. **Mode 切换**：只在 Mymain 层改 `next_mode`，业务 Mode 内不要直接操作 `curr_mode`。
10. **退出 Mode_3 等调参模式**要恢复 `Angle_Ring_Enable = 1`（参考 Mode_3_Exit 的写法）。
11. **20ms Tick 链顺序**：IMU → Con_Task → Mode → 电机速度环，新增 Tick 逻辑按此插入。
12. 工程所有 .c/.h 均 UTF-8 编码，写新文件保持 UTF-8。

## 11. 常用开发流程速查

### 新增一个 Mode（示例 Mode_7）
1. 复制 `Mode_4.c/h` → `Mode_7.c/h`，改函数名与显示文本
2. `Mode_G.h` 枚举在 `Mode_End` 前加 `Mode_7`
3. `Mode_G.c` 20ms Tick switch 加 `case Mode_7:`
4. `Mymain.c` 三处 switch（Loop/Exit/Setup）加 case
5. `AllHeader.h` Mode 库组加 `#include "Mode_7.h"`
6. Keil 工程加入 Mode_7.c（用户操作）

### 新增持久化参数
1. `Mode_1.c` 的 `s_AT_Params[]` **末尾**追加 `{ AT_PARAM_F(&全局变量, 默认值) }`
2. 需要时可 `PARAM_FORCE(变量, 新默认值)` 推送一次（用完注释）
3. Mode_1_Setup 里 `Param_Register("名称", &变量, 步进, PARAM_FLOAT)` 加入编辑器

### 串口加 DMA（USART2/3/UART4）
1. CubeMX 给目标串口加 RX/TX 两个 DMA（NORMAL、Byte），重新生成
2. 编译即可 —— 串口层自动切换 DMA 收发 + 缓存维护，**无需改代码**

### 调参工作流
- 脱机调参：KEY0 → Mode_1，EC11 选参数，KEY_3 保存到 AT24C02
- 任务调参：KEY0 → Mode_3，KEY_1 单击选任务、长按入队/跳过
- 上位机：USART1 接 VOFA，ABC 协议 `@关键字...$#` 实时改参数

### 移植新芯片
只改 `MySystem/`（见 §4.5），上层代码零修改。
