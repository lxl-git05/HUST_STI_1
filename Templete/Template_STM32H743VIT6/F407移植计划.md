# F407 → H743 移植计划（执行中）

> 源工程：`Templete_STM32F407ZGT6\Template_F407ZGT6`
> 创建：2026-08-14

## 一、范围与约定

**移植**：通用库 + 调参体系(AT24C02/ParamEdit/EC11) + 任务队列 + IMU + TJC_LCD
**排除**：蜂鸣器、舵机(本次不写)、Stepper/Orange/Y8U/Con_Mode/RGB/Elec/Laser/Match

**硬性约定**：
- 串口：接收用中断 `HAL_UARTEx_ReceiveToIdle_IT`，发送阻塞 `HAL_UART_Transmit`；照 F4 功能对齐，不做 DMA 大改
- AT 相关库放新建 `AT/` 文件夹（同 IMU/ 风格）：bsp_at24c02、at24c02_manager、Param_AT24C02、ParamEdit
- Keil 工程由用户自己加文件/路径
- H743 现有 Con_Motor/Motor/MyPID/Mode_2 业务保留不覆盖
- 修改 CubeMX 生成文件（it.c 等）一律放 USER CODE 区
- 每步编译通过再进下一步

**环境事实**：SYSCLK 480MHz / HCLK 240MHz / APB1&2 120MHz / 定时器 240MHz；TIM16=20ms、TIM17=1ms、TIM7=Delay_Us（tim.h:67 已声明）；EC11=PC4/PC5(EXTI, NVIC 未使能)+PB0；USART3/UART4 已 CubeMX 配置但 NVIC 未使能；I2C1=PB6/PB7 硬件已配、当前无人使用；工程无 DMA 配置；LQFP100 无 PF/PG 口。

### 步骤 3 ✅：EC11 旋转编码器 Encoder_Key

**目标**：移植 F4 的 EC11 旋转计数驱动，为 ParamEdit 调参 UI 提供旋钮输入。

**验证**：正转 `Encoder_Get()` 返回正数、反转返回负数，读取后清零；无漏脉冲。
