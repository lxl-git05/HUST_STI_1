## 1. 工程概述

本工程是一个**高度模块化、芯片无关**的 STM32F407ZGT6 嵌入式模板，适用于云台控制、机器人运动等场景。核心特性：

| 特性 | 说明 |
|------|------|
| **分层架构** | 6 层分离：Core/Drivers → MySystem → Hardware/Software/Tools → Function → Mode → Top |
| **芯片无关** | MySystem 抽象层隔离所有 HAL 依赖，跨芯片移植只需改一层 |
| **多模式状态机** | 5 种运行模式（全局 + Mode_1~4），按键切换，支持模式记忆 |
| **双协议串口** | ABC 文本协议 + HEX 二进制协议，DMA + 空闲中断，自动解析 |
| **参数持久化** | AT24C02 EEPROM 三级架构，注册制自动地址分配，掉电不丢失 |
| **步进驱动** | 速度模式 + 位置模式（T型/三角形曲线），双层限位，加速度 ramp |
| **PID 控制** | 位置式 PID，P/I/D 分离，积分限幅，微分先行，不完全微分，死区 |
| **OLED 交互** | SPI 软件模拟驱动，中文/ASCII 显示，编码器参数编辑器 |
| **香橙派通信** | 通过 USART2 与上位机（香橙派）进行视觉数据交互 |

### 硬件资源一览

| 外设 | 型号/引脚 | 用途 |
|------|----------|------|
| MCU | STM32F407ZGT6, 168MHz | 主控 |
| 步进电机1 | PE5(TIM9_CH1) + PE6(DIR) | 水平云台 |
| 步进电机2 | PB14(TIM12_CH1) + PB15(DIR) | 竖直云台 |
| 舵机×4 | PE9/PE11/PE13/PE14 (TIM1) | 舵机控制 |
| 直流电机×2 | PD14/PD15 (TIM4) | 直流电机 |
| 编码器×2 | PA0/PA1 (TIM2), PA6/PA7 (TIM3) | 电机编码器 |
| OLED | PB8(SCL)/PB9(SDA) 软件I2C | 显示 |
| EEPROM | PA4(SCL)/PA5(SDA) AT24C02 | 参数存储 |
| EC11 编码器 | PF3/PF7 + PF5(按键) | 旋转输入 |
| RGB LED | PG2/PG4/PG6 共阳极 | 状态指示 |
| 按键×4 | PE3/PE4/PF4/PF5 | 用户输入 |
| USART1 | PA9/PA10, DMA2 | 调试/上位机 |
| USART2 | PA2/PA3, DMA1 | 香橙派通信 |

## 2. 分层架构

```
┌───────────────────────────────────────────┐
│  Top    (Mymain / AllHeader)  调度+初始化 │  ← 主循环，模式分发
├───────────────────────────────────────────┤
│  Mode   (Mode_G / Mode_1~4)   状态机     │  ← 模式定义，Setup/Loop/Exit/Tick
├───────────────────────────────────────────┤
│  Function (电机/舵机/串口)    功能组合    │  ← 组合 Hardware+Software 实现业务
├───────────────────────────────────────────┤
│  Hardware (Motor/Servo/Key/OLED) 设备驱动 │  ← 物理设备抽象
├───────────────────────────────────────────┤
│  Software (PID/Task)          软件算法    │  ← 纯算法，无硬件依赖
├───────────────────────────────────────────┤
│  Tools   (LED_Flash/TimerCounter)         │  ← 通用工具
├───────────────────────────────────────────┤
│  MySystem ★ 芯片抽象层 ★  唯一切换点      │  ← GPIO/PWM/Encoder/Timer 封装
├───────────────────────────────────────────┤
│  Core + Drivers  HAL库 + CubeMX生成        │  ← STM32 官方 HAL
└───────────────────────────────────────────┘
```

### 各层职责

| 层 | 依赖方向 | 芯片相关 | 说明 |
|----|---------|---------|------|
| **Core/Drivers** | 无 | ✅ 是 | CubeMX 生成的 HAL 层代码 |
| **MySystem** | Core/Drivers | ✅ 是 | 芯片抽象层，隔离 HAL 依赖 |
| **Hardware** | MySystem | ❌ 否 | 设备驱动，仅依赖 MySystem 抽象接口 |
| **Software** | MySystem | ❌ 否 | 纯算法（PID、参数管理），无硬件依赖 |
| **Tools** | MySystem | ❌ 否 | LED闪烁、代码计时等通用工具 |
| **Function** | Hardware + Software | ❌ 否 | 业务功能组合层 |
| **Mode** | Function + Hardware | ❌ 否 | 模式状态机，定义各模式行为 |
| **Top** | Mode + AllHeader | ❌ 否 | 主循环调度、全局初始化 |

**核心原则**：MySystem 以上所有层代码与芯片型号无关。换芯片只需修改 MySystem 和 Core/Drivers。

## 4. 模式变换系统

### 4.1 模式枚举

```c
typedef enum {
    Mode_Null = 0U,    // 空模式（仅 Global 在运行）
    Mode_1,            // 脱机调参模式：OLED参数编辑器 + AT24C02持久化
    Mode_2,            // 实验模式：新功能开发测试
    Mode_3,            // 云台PID调参模式：串口在线调参
    Mode_4,            // 业务逻辑模式（预留）
    Mode_End,          // ★ 模式尽头标记，不能在此之后添加
} Mode_Typedef;
```

### 4.2 模式约定

| Mode | 用途 | 说明 |
|------|------|------|
| **Mode_Null** | 空模式 | 仅全局 Mode_G 运行，OLED 显示 "===Mode_G===" |
| **Mode_1** | 脱机调参 | OLED 参数编辑器，编码器调整，AT24C02 持久化 |
| **Mode_2** | 实验代码 | **所有新实验代码写在这里** |
| **Mode_3** | PID 调参 | 通过 USART1 接收串口指令调 PID，实时打印角度曲线 |
| **Mode_4** | 业务逻辑 | 预留，具体业务功能 |

### 4.3 每个 Mode 的标准接口

每个 Mode 文件必须实现 4 个标准函数：

```c
// Mode_X.h
void Mode_X_Setup(void);  // 进入该模式时调用一次（初始化）
void Mode_X_Loop(void);   // 主循环每次迭代调用
void Mode_X_Tick(void);   // 20ms 定时中断调用
void Mode_X_Exit(void);   // 离开该模式时调用一次（清理）
```

### 4.4 模式切换机制

**切换触发**：在 Mode_G_Loop 中检测 KEY_0 双击

```c
// Mode_G.c — 模式切换入口
void Mode_G_Loop(void) {
    if (Key_Check(KEY_0, KEY_DOUBLE)) {
        Mode_To_Next();   // 循环切换到下一个模式
    }
}

void Mode_To_Next(void) {
    uint32_t next_val = (uint32_t)next_mode + 1;
    next_mode = (next_val >= (uint32_t)Mode_End) ? Mode_Null : (Mode_Typedef)next_val;
}
```

**切换流程**（在 Mymain 主循环中）：

```
curr_mode == next_mode → 运行当前模式的 Loop()
curr_mode != next_mode → 先 Exit() 旧模式 → Setup() 新模式 → curr_mode = next_mode
```

```c
// Top/Mymain.c — 核心调度逻辑
void Mymain(void) {
    Mode_G_Setup();   // 全局初始化

    while (1) {
        OLED_Clear();
        Mode_G_Loop();   // 全局逻辑（含按键检测、模式切换）

        if (curr_mode == next_mode) {
            // 正常运行当前模式
            switch (curr_mode) {
                case Mode_Null: break;
                case 1: Mode_1_Loop(); break;
                case 2: Mode_2_Loop(); break;
                case 3: Mode_3_Loop(); break;
                case 4: Mode_4_Loop(); break;
            }
        } else {
            // 模式切换：Exit旧 → Setup新
            // ... (Exit + Setup 逻辑)
            curr_mode = next_mode;

            // ★ 记忆模式：保存到 AT24C02，下次上电自动恢复
            if (curr_mode != Mode_Null)
                Param_AT24C02_Write(&curr_mode);
        }
        OLED_Update();
    }
}
```

### 4.5 模式记忆

每次成功切换模式后，自动将新模式保存到 AT24C02，下次上电时自动恢复到上次关机时的模式。

```
上电 → Param_AT24C02_Init() → 从 EEPROM 恢复 curr_mode
     → if (curr_mode > Null && curr_mode < End):
          next_mode = curr_mode; curr_mode = Null  // 触发完整切换流程
```

| 场景 | 行为 |
|------|------|
| 首次上电（EEPROM 空白） | 进 Mode_1（AT 注册宏默认值） |
| 正常工作切模式后断电 | 下次上电恢复到上次关机时的模式 |
| 切到 Mode_Null 再断电 | Mode_Null 不保存，回到上一个有效模式 |

## 5. 串口通信系统

### 5.1 串口配置

| 串口 | 引脚 | 波特率 | DMA TX | DMA RX | 用途 |
|------|------|--------|--------|--------|------|
| **USART1 (Serial1)** | PA9 / PA10 | 115200 | DMA2_Stream7 | DMA2_Stream2 | 调试/上位机通信 |
| **USART2 (Serial2)** | PA2 / PA3 | 115200 | DMA1_Stream6 | DMA1_Stream5 | 香橙派视觉数据 |
| USART3 | PB10 / PB11 | 115200 | — | — | 未使用 |
| USART6 | PC6 / PC7 | 115200 | — | — | 未使用 |

### 5.2 双协议支持

本系统同时支持两种通信协议，由空闲中断自动识别分发：

| 协议 | 帧格式 | 用途 |
|------|--------|------|
| **ABC 协议** | `[@][DATA...][$][#]` | 文本指令，人机交互 |
| **HEX 协议** | `[0xFF][0xAA][LEN][D1_H][D1_L][D1_CK]...[0x55][0xFE]` | 二进制数据传输，机器通信 |

### 5.3 串口实例结构体

```c
typedef struct {
    USART_TypeDef      *Instance;      // USART外设基址
    UART_HandleTypeDef *huart;         // HAL句柄
    uint8_t  rxBuf[Serial_RX_BUF_SIZE]; // 接收缓冲区
    uint16_t rxLen;                    // 本次接收数据长度
    Serial_ABC_Data_Typedef ABC_Data;  // ABC协议数据
    Serial_HEX_Data_Typedef HEX_Data;  // HEX协议数据
} Serial_Typedef;

extern Serial_Typedef Serial1;  // USART1
extern Serial_Typedef Serial2;  // USART2
```

### 5.4 ABC 协议详解

**帧格式**: `[@][数据内容...][$][#]`

**帧定义**:
- 帧头: `@` (0x40)
- 帧尾1: `$` (0x24)
- 帧尾2: `#` (0x23)

**示例**:
```
@Kp=1.5$#             → 设置 Kp 参数
@angle_shift:50$#     → 设置角度偏移
@start:6$#            → 请求数据传输
@Get$#                → 确认接收
```

**API**:

```c
// 发送 ABC 格式字符串
void Serial_printf(Serial_Typedef *pSerial, const char *fmt, ...);

// 从接收到的 ABC 包中提取浮点数
bool Serial_SetFloatData(Serial_Typedef *pSerial, char *KeyWord, char *cmd, float *Data);

// 从接收到的 ABC 包中提取整数
bool Serial_SetIntData(Serial_Typedef *pSerial, char *KeyWord, char *cmd, int *Data);

// 检查是否收到指定关键字
bool Serial_Check_Str(Serial_Typedef *pSerial, char *KeyWord);

// 获取新包标志（读取后自动清零）
uint8_t Serial_GetNewPackageFlag_ABC(Serial_Typedef *pSerial);
```

**使用示例 — 接收 ABC 指令**:

```c
// 在 Loop 中检测 ABC 指令
if (Serial_GetNewPackageFlag_ABC(&Serial1)) {
    // 尝试匹配 "Kp=xxx" 指令
    Serial_SetFloatData(&Serial1, "Kp", "Kp=%f", &Stepper1.PID_Angle.Kp);
    Serial_SetFloatData(&Serial1, "Ki", "Ki=%f", &Stepper1.PID_Angle.Ki);
    Serial_SetFloatData(&Serial1, "Kd", "Kd=%f", &Stepper1.PID_Angle.Kd);
}
```

**使用示例 — 发送 ABC 数据**:

```c
// 向香橙派发送角度偏移参数
Serial_printf(&Serial2, "@angle_shift:%d$#", angle_shift);
Serial_printf(&Serial2, "@offset:%d$#", offset);

// 向调试串口打印 PID 实时数据（CSV 格式）
Serial_printf(&Serial1, "%.2f,%.2f,%.2f\n",
    Stepper1.PID_Angle.goalPoint,
    Stepper1.PID_Angle.realPoint_Now,
    Stepper1.PID_Angle.setPoint);
```

### 5.5 HEX 协议详解

**帧格式**: `[0xFF][0xAA][LEN][D1_H][D1_L][D1_CK][D2_H][D2_L][D2_CK]...[DN_H][DN_L][DN_CK][0x55][0xFE]`

| 字节 | 含义 |
|------|------|
| 0xFF, 0xAA | 帧头 |
| LEN | 数据字个数（每个字 = 1个 int16_t） |
| Dx_H | 第 x 个字的高 8 位 |
| Dx_L | 第 x 个字的低 8 位 |
| Dx_CK | 校验码 = Dx_H ^ Dx_L |
| 0x55, 0xFE | 帧尾 |

**数据容量**: 最多 256 个字（768 字节数据区），总帧 ≤ 775 字节

**API**:

```c
// 获取第 index 个字的数据（0-based）
int16_t Serial_GetHexData(Serial_Typedef *pSerial, uint8_t index);

// 获取本帧实际字数
uint8_t Serial_GetHexLen(Serial_Typedef *pSerial);

// 获取新包标志（读取后自动清零）
uint8_t Serial_GetNewPackageFlag_HEX(Serial_Typedef *pSerial);

// 获取 HEX 错误码
int Serial_GetError_HEX(Serial_Typedef *pSerial);
```

**使用示例 — 接收香橙派 HEX 数据**:

```c
// Orange.c — 20ms 周期调用
void Oran_Update(void) {
    if (Serial_GetNewPackageFlag_HEX(&Serial2)) {
        uint8_t cmd = Serial_GetHexData(&Serial2, 0);  // 第0字：命令类型
        if (cmd == 0) {
            // 正常数据：x_real(字1), y_real(字2), x_tar(字3), y_tar(字4)
            x_real = (float)Serial_GetHexData(&Serial2, 1);
            y_real = (float)Serial_GetHexData(&Serial2, 2);
            x_tar  = (float)Serial_GetHexData(&Serial2, 3);
            y_tar  = (float)Serial_GetHexData(&Serial2, 4);
        } else if (cmd == 1) {
            // 调阈值数据
            angle_shift = Serial_GetHexData(&Serial2, 1);
            offset      = Serial_GetHexData(&Serial2, 2);
            black_h     = Serial_GetHexData(&Serial2, 3);
            black_s     = Serial_GetHexData(&Serial2, 4);
            black_v     = Serial_GetHexData(&Serial2, 5);
        }
    }
}
```

### 5.6 接收机制 — DMA + 空闲中断

串口使用 `HAL_UARTEx_ReceiveToIdle_DMA` 进行接收，空闲中断触发时自动解析：

```
USART1/2 → DMA 循环接收 → 空闲中断 → HAL_UARTEx_RxEventCallback
  → 识别帧头 (0xFF,0xAA → HEX | '@' → ABC)
  → 解析帧 → 置位 frame_valid / Serial_New_Package_Flag
  → 重新启动 DMA 接收
```

### 5.7 错误码

```c
typedef enum {
    Serial_Err_None         = 0x00,
    Serial_Err_ABC_Head     = 0x01,   // ABC帧头错误
```

## 6. 记忆外存系统 (AT24C02)

### 6.1 三层架构

```
Param_AT24C02 (Function)     — 业务层：定义哪些变量需要持久化
    ↓ 调用
at24c02_manager (Software)   — 管理层：注册、地址自动分配、读写协调
    ↓ 调用
bsp_at24c02 (Hardware)       — 驱动层：软件 I2C 字节级读写
```

### 6.2 硬件连接

| 信号 | 引脚 | 说明 |
|------|------|------|
| AT_SCL | PA4 | 软件 I2C 时钟 |
| AT_SDA | PA5 | 软件 I2C 数据 |
| 设备地址 | 0xA0(写) / 0xA1(读) | 7位地址 0x50 左移 1 位 |

### 6.3 底层驱动 — bsp_at24c02

提供**软件 I2C + 硬件 I2C 两种模式**，通过宏切换：

```c
#define AT24C02_USE_SW_I2C    1   // 1=软件I2C(GPIO模拟), 0=硬件I2C
```

**底层 API**:

```c
void    AT24C02_Init(void);                               // 初始化
uint8_t AT24C02_WriteByte(uint8_t WordAddress, uint8_t Data);  // 写1字节
uint8_t AT24C02_ReadByte(uint8_t WordAddress);                // 读1字节
```

**软件 I2C 时序参数**:
- NOP 延时: `× 19`（168MHz 下校准，约 1μs/NOP循环）
- 写周期等待: `HAL_Delay(5)` ms/字节

### 6.4 注册制管理层 — at24c02_manager

**核心机制**：变量通过注册宏注册到参数表，地址自动顺序分配。

**注册宏**:

```c
AT_PARAM_I8(&var, default)    // int8_t,  1 字节
AT_PARAM_I16(&var, default)   // int16_t, 2 字节

```

### 6.5 业务层 — Param_AT24C02

对外暴露简洁的业务接口：

```c

uint8_t Param_AT24C02_Write(void *varPtr);  // 写单个变量
uint8_t Param_AT24C02_Read(void *varPtr);   // 读单个变量
```

### 6.6 PARAM_FORCE 宏 — 手动推送默认值

```c
#define PARAM_FORCE(var, val)  do { (var) = (val); Param_AT24C02_Write(&(var)); } while(0)
```

**用途**：固件升级后，手动将新的默认值推送到 EEPROM。

**使用流程**:
1. 在 `Mode_G.c` 的 `Mode_G_Setup()` 中取消对应行注释并改值
2. 编译烧录一次（新值覆盖 EEPROM）
3. 重新注释掉（否则每次上电都覆盖用户调好的值）

```c
// Mode_G.c — Mode_G_Setup()
// PARAM_FORCE(curr_mode, Mode_1);                 // 强制默认从 Mode_1 启动
// PARAM_FORCE(Stepper1.PID_Angle.Kp, 0.217f);     // 强制默认 Kp 值
// PARAM_FORCE(angle_shift, 50);                   // 强制默认角度偏移
```

### 6.7 参数表布局规则

> **☆ 重要**: `s_AT_Params[]` 数组顺序一旦确定，**不要改顺序、不要增删**。  
> 改顺序或增删会导致 EEPROM 旧数据和新布局错位。  
> 必须改时，先 `EraseAll()` + `PARAM_FORCE` 重推所有默认值。

### 6.8 完整使用示例

```c
// ========== 定义需要持久化的全局变量 ==========

float g_pidKi = 0.0f;
float g_pidKd = 0.0f;
int8_t g_mode = 0;

    { AT_PARAM_I8(&g_mode, 0) },
    { AT_PARAM_F(&g_pidKp, 1.0f) },
    { AT_PARAM_F(&g_pidKi, 0.0f) },
    { AT_PARAM_F(&g_pidKd, 0.0f) },
};

// ========== 初始化 ==========
void Param_AT24C02_Init(void) {
    for (int i = 0; i < At_Size; i++)
        AT_Manager_Register(&s_AT_Params[i]);
    AT_Manager_Init();  // 从EEPROM恢复，失败用默认值
}

// ========== 运行时读写 ==========

Param_AT24C02_Write(&g_pidKp);   // 立即持久化
Param_AT24C02_Read(&g_pidKp);    // 从EEPROM读回
Param_AT24C02_SaveAll();         // 批量保存所有参数
```

## 7. 步进电机驱动系统

### 7.1 系统概述

`Stepper_PWM` 是基于 STM32 定时器 PWM 的步进电机驱动库，支持**两台步进电机**（云台水平和竖直方向）。

**核心能力**:

| 功能 | 说明 |
|------|------|
| **速度模式** | 开环速度控制，支持加速度 ramp（1ms 粒度丝滑调速） |
| **位置模式** | T 型/三角形速度曲线精确定位，基于匀加速运动公式 |
| **快速到位** | acc=0 时直接以最大速度运行，脉冲中断级停止 |
| **双层限位** | 软件角度限位：前置门禁 + 脉冲中断兜底 |
| **多电机** | 同结构体支持任意数量实例 |
| **芯片无关** | 通过 MySystem 抽象层隔离 HAL |

### 7.2 硬件连接

| 信号 | 步进电机1 (水平) | 步进电机2 (竖直) |
|------|:---------------:|:---------------:|
| Stp (脉冲) | **PE5** — TIM9_CH1, AF3 | **PB14** — TIM12_CH1, AF9 |
| Dir (方向) | **PE6** — GPIO | **PB15** — GPIO |
| En (使能) | PC0 — GPIO | PC2 — GPIO |

**定时器参数**:

| 参数 | 电机1 (TIM9) | 电机2 (TIM12) |
|------|:-----------:|:------------:|
| 总线 | APB2 (168MHz) | APB1 (84MHz) |
| 预分频器 | 168-1 | 84-1 |
| 计数时钟 | **1 MHz** | **1 MHz** |
| ARR 范围 | 1~65535 | 1~65535 |
| 频率范围 | ~15Hz ~ 500kHz | ~15Hz ~ 500kHz |

**电机参数**（默认）:
- 步进角: 1.8°/脉冲
- 细分: 16 细分
- 脉冲当量: **0.1125°/脉冲** (360° / 3200脉冲)

### 7.3 核心结构体


### 7.5 位置模式算法

**数学基础**（从连续域推导）：

```
已知: dv/dt = a,  dN/dt = 6v/φ   (φ = pulse_angle)
推导: v² = v₀² + (a·φ/3)·N
      N  = (v² - v₀²) × 3 / (a × φ)
```

**场景判定**（在 `Pos_Set_Abs` 中预计算）：

```
if 2 × acc_steps_full ≥ total_steps:
  → 场景B (三角形): 行程不足，无法达到 max_speed
    acc_steps = total_steps / 2
    cruise_steps = 0
else:
  → 场景A (梯形): 行程充足，能加速到 max_speed
    acc_steps = acc_steps_full
    cruise_steps = total_steps - 2 × acc_steps
```

**速度曲线**:

```
场景A (梯形):             场景B (三角形):
Speed                     Speed
  ↑     ┌────────┐          ↑     ╱╲
  │    ╱          ╲         │    ╱  ╲
  │   ╱            ╲        │   ╱    ╲
  │  ╱              ╲       │  ╱      ╲
  └─┴──────────────┴──→Steps└─┴────────┴──→Steps
    acc  cruise  dec           acc    dec
```

### 7.6 双层限位保护

```
第1层 (前置门禁) — _Stepper_Apply_Speed 入口
  └─ 速度模式: Limit_Check 检查目标方向是否超限
  └─ 位控模式: ★ 跳过（信任位置目标，有 Layer2 兜底）

第2层 (脉冲中断兜底) — Pulse_Count 每个脉冲后
  └─ 所有模式通用
  └─ 超限 → 立即 Stop + RGB 亮红灯
```

### 7.7 速度模式与位置模式互斥

```
Speed_Set 被调用
  → Pos_Phase = IDLE (取消位控)
  → 开始速度 ramp

Pos_Set_Abs / Pos_Set_Rel 被调用
  → Speed_Tar = 0, Acc_Val = 0 (取消速度 ramp)
  → 开始位控规划

同时只有一个模式在控制速度输出。
```

```c
        Stepper1.Pos_Phase = POS_PHASE_IDLE;

    // 到位后触发下一段

                Stepper_PWM_Pos_Set_Rel(&Stepper1, -180.0f, 120.0f, 60.0f);
                break;
            case A_REV:

                break;
        }
```

## 8. MySystem 芯片抽象层与跨芯片移植

### 8.1 设计目标

MySystem 是工程中**唯一**与芯片型号相关的层，所有上层代码通过 MySystem 的抽象接口访问硬件，完全不感知底层芯片型号。

### 8.2 抽象接口一览

| 模块 | 抽象结构体 | 功能 |
|------|-----------|------|
| **MyGPIO** | `MyGPIO_Typedef {GPIO_TypeDef*, uint16_t}` | GPIO 读写 |

|--------|------|------|--------|-----|--------|
| TIM6 | 1ms 系统 Tick | 1ms | 84-1 | 1000-1 | 0（最高） |
| TIM7 | 20ms 系统 Tick | 20ms | 84-1 | 20000-1 | 0（最高） |

| TIM12 | 步进2 脉冲计数 | 随速度变化 | 84-1 | 动态 | 1 |

**弱回调机制**：
```c
// MyTimer.c — 定义弱函数（默认空实现）
__attribute__((weak)) void Timer_1ms_Callback(void) {}
__attribute__((weak)) void Timer_20ms_Callback(void) {}
__attribute__((weak)) void Timer_Stepper1_Pulse_Callback(void) {}
__attribute__((weak)) void Timer_Stepper2_Pulse_Callback(void) {}

// HAL 中断回调 → 判断定时器实例 → 分发到弱回调
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
    if (htim->Instance == TIM6)  Timer_1ms_Callback();
    if (htim->Instance == TIM7)  Timer_20ms_Callback();
    if (htim->Instance == TIM9)  Timer_Stepper1_Pulse_Callback();
    if (htim->Instance == TIM12) Timer_Stepper2_Pulse_Callback();
}
```

## 9. 定时器与中断系统

### 9.1 系统 Tick 调度

```
TIM6 (1ms, prio=0 最高)
  → HAL_TIM_PeriodElapsedCallback → Timer_1ms_Callback (Mode_G.c)
      ├─ Key_Tick()                 ← 按键扫描
      ├─ Flash_Mode_Tick()          ← LED 闪烁
      ├─ Speed_Tick(&Stepper1)      ← 步进1 速度 ramp
      ├─ Speed_Tick(&Stepper2)      ← 步进2 速度 ramp
      ├─ Pos_Tick(&Stepper1)        ← 步进1 位控状态机
      └─ Pos_Tick(&Stepper2)        ← 步进2 位控状态机

TIM7 (20ms, prio=0)
  → HAL_TIM_PeriodElapsedCallback → Timer_20ms_Callback (Mode_G.c)
      ├─ Oran_Update()              ← 香橙派 HEX 数据接收
      └─ Mode_X_Tick()              ← 当前模式 20ms 业务逻辑
           └─ Stepper_PID_Tick(20)  ← PID 计算 + 速度输出 (Mode_3)
```

### 9.2 步进电机脉冲中断链路

```
TIM9 更新 (Stepper1, prio=1)          TIM12 更新 (Stepper2, prio=1)
  → TIM1_BRK_TIM9_IRQHandler            → TIM8_BRK_TIM12_IRQHandler
  → HAL_TIM_IRQHandler(&htim9)          → HAL_TIM_IRQHandler(&htim12)
  → HAL_TIM_PeriodElapsedCallback       → HAL_TIM_PeriodElapsedCallback
  → Timer_Stepper1_Pulse_Callback       → Timer_Stepper2_Pulse_Callback
  → Stepper_PWM_Pulse_Count(&S1)        → Stepper_PWM_Pulse_Count(&S2)
      ├─ Pos_Now ±= pulse_angle            ├─ Pos_Now ±= pulse_angle
      ├─ 位控: Pos_StepCnt++/到位停止       ├─ 位控: Pos_StepCnt++/到位停止
      └─ Layer2 限位检查                   └─ Layer2 限位检查
```

### 9.3 串口空闲中断

```
USART1/2 DMA 接收 → 空闲中断 → HAL_UARTEx_RxEventCallback
  → 识别协议 → 解析帧 → 置位标志 → 重启 DMA
```

### 9.4 EC11 编码器中断

```
EXTI3 (PF3, EC11 A相下降沿) → EXTI3_IRQHandler → HAL_GPIO_EXTI_IRQHandler
EXTI9_5 (PF7, EC11 B相下降沿) → EXTI9_5_IRQHandler → HAL_GPIO_EXTI_IRQHandler
  → HAL_GPIO_EXTI_Callback (在 Encoder_Key.c 中重写) → 累计增量
```

### 9.5 Timer_Counter — 代码执行时间测量

```c

void Timer_Counter_Begin(void);    // 开始计时
```

## 10. PID 控制系统

### 10.1 PID 结构体

```c
typedef struct PID {
    float goalPoint;       // 目标值
    float Kp, Ki, Kd;      // PID 系数
    float LastError;       // 上次误差
    float PreError;        // 本次误差
    float SumError;        // 累积积分

    float realPoint_Now;   // 当前真实值（反馈）
    float realPoint_Bef;   // 上次真实值

    float pout, iout, dout; // P/I/D 各分量输出

    float OutMax, OutMin;  // 输出限幅
    float ioutMax;         // 积分限幅
    float deadspace;       // 死区
    float d_style;         // 微分先行系数 (0~1)
    float d_filter;        // 不完全微分滤波系数 (0~1)

    void (*PID_Func)(void); // 自定义处理函数指针

    float setPoint;        // 最终输出值
} Pid_Typedef;
```

### 10.2 PID API

```c
// 初始化（标准配置：Kp, Ki, Kd, 输出上限, 输出下限, 积分上限）
void PID_Init(Pid_Typedef *pid, float kp, float ki, float kd,
              float OutMax, float OutMin, float ioutMax);

// 更新一次 PID 计算（传入实际值，结果写入 setPoint）
void PID_Update(Pid_Typedef *pid, float ActualValue);
```

### 10.3 PID 特性

| 特性 | 说明 | 配置方法 |
|------|------|----------|
| **P/I/D 分离** | 各分量独立计算和输出 | 内置，自动 |
| **积分限幅** | 防止积分饱和 | `ioutMax` 参数 |
| **微分先行** | 微分作用于测量值而非误差，减少设定值突变冲击 | `d_style` (0~1) |
| **不完全微分** | 一阶低通滤波，抑制高频噪声 | `d_filter` (0~1) |
| **输出死区** | 小误差时不输出，避免抖动 | `deadspace` |
| **输出限幅** | 最终输出钳位 | `OutMax / OutMin` |
| **自定义函数** | 可挂载特殊处理回调 | `PID_Func` 函数指针 |

### 10.4 使用示例

```c
Pid_Typedef myPID;

// 初始化: Kp=0.5, Ki=0.01, Kd=0.1, 输出限幅±100, 积分限幅1000
PID_Init(&myPID, 0.5f, 0.01f, 0.1f, 100.0f, -100.0f, 1000.0f);

// 可选: 启用微分先行 (0.5=50%)
myPID.d_style = 0.5f;

// 可选: 启用不完全微分滤波 (0.3=一阶滤波系数)
myPID.d_filter = 0.3f;

// 设置目标
myPID.goalPoint = 90.0f;

// 每次更新传实际值
PID_Update(&myPID, currentAngle);
float output = myPID.setPoint;   // 获取 PID 输出

// 监控各分量
printf("P=%.2f I=%.2f D=%.2f Out=%.2f\n",
       myPID.pout, myPID.iout, myPID.dout, myPID.setPoint);
```

## 11. OLED 参数编辑器

### 11.1 概述

ParamEdit 是一个基于 OLED 显示屏和 EC11 旋转编码器的**离线参数编辑器**，允许用户在不连接上位机的情况下调整和保存参数。

### 11.2 交互模型

| 操作 | 按键 | 说明 |
|------|------|------|
| 进入/退出编辑 | KEY_1 长按 1s | 切换编辑/正常模式 |
| 下一个参数 | KEY_1 单击 | 光标下移，到末尾回绕 |
| 上一个参数 | KEY_1 双击 | 光标上移，到开头回绕 |
| 修改参数值 | 旋转编码器 | 步长 × 旋转增量 |
| 保存到 EEPROM | KEY_3 (编码器按键) 单击 | 仅保存已修改的 AT 参数 |

> **注意**: KEY_0 被 Mode_G 占用（模式切换），ParamEdit 不得使用。

### 11.3 按键映射配置

```c
// ParamEdit.h — 修改此处即可切换按键功能
#define PARAM_KEY_ENTER_EXIT    KEY_1       // 进入/退出（长按）
#define PARAM_KEY_NEXT          KEY_1       // 下一个参数（单击）
#define PARAM_KEY_PREV          KEY_1       // 上一个参数（双击）
#define PARAM_KEY_SAVE          KEY_3       // 保存（单击）
```

### 11.4 API

```c
void Param_Init(void);                                          // 初始化/清空参数表
void Param_Register(const char *name, void *var, float step, ParamType type); // 注册参数
void Param_Loop(void);                                          // 主循环调用，运行状态机
int  Param_IsActive(void);                                      // 返回 1=编辑模式, 0=正常
```

### 11.5 参数类型

```c
typedef enum {
    PARAM_INT8,    // int8_t
    PARAM_INT16,   // int16_t
    PARAM_INT32,   // int32_t
    PARAM_FLOAT    // float
} ParamType;
```

### 11.6 AT24C02 联动

```c
#define PARAM_USE_AT24C02   1   // 1=启用 AT24C02 联动, 0=完全解耦
```

启用后，ParamEdit 会自动：
- 通过变量指针反查 AT 表，标记 `is_at=1` 的参数
- 进入编辑模式时从 EEPROM 加载存储值
- 修改后标记 `dirty=1`，OLED 显示 `*` 号
- KEY_3 保存时调用 `AT_Manager_Write` 写入 EEPROM

### 11.7 完整使用示例

```c
// Mode_1_Setup() — 初始化参数编辑器
void Mode_1_Setup(void) {
    OLED_Clear();
    Param_Init();   // 清空参数表

    // 注册 UI 参数（自动关联 AT 表）
    Param_Register("curr_mode",   &curr_mode,             1,     PARAM_INT8);
    Param_Register("Stp1_Kp",    &Stepper1.PID_Angle.Kp, 0.01f, PARAM_FLOAT);
    Param_Register("Stp1_Kd",    &Stepper1.PID_Angle.Kd, 0.01f, PARAM_FLOAT);
    Param_Register("Stp2_Kp",    &Stepper2.PID_Angle.Kp, 0.01f, PARAM_FLOAT);
    Param_Register("Stp2_Kd",    &Stepper2.PID_Angle.Kd, 0.01f, PARAM_FLOAT);
    Param_Register("angle_shift",&angle_shift,            1,     PARAM_INT16);
}

// Mode_1_Loop() — 运行编辑器
void Mode_1_Loop(void) {
    OLED_Printf(0, 0, OLED_6X8, "=====Mode_1=====");

    if (!Param_IsActive()) {
        // 非编辑模式：正常业务逻辑
        if (Key_Check(KEY_0, KEY_LONG)) {
            Serial_printf(&Serial2, "@start:6$#");  // 请求香橙派数据
        }
    }

    Param_Loop();  // 处理编辑器状态机（自动绘制 OLED）
}
```

### 11.8 初始化顺序

```
Param_AT24C02_Init()  → 注册 AT 参数 + 从 EEPROM 恢复值
Param_Init()          → 清空 ParamEdit 参数表
Param_Register(...)   → 注册 UI 参数（自动关联 AT 表、加载存储值）
```

### 13.1 启动流程图

```
main()
  ├─ HAL_Init()                     // HAL 库初始化
  ├─ SystemClock_Config()           // 时钟配置 (168MHz)
  ├─ MX_GPIO_Init()                 // GPIO 初始化
  ├─ MX_DMA_Init()                  // DMA 初始化
  ├─ MX_ADC1_Init()                 // ADC 初始化
  ├─ MX_I2C1_Init() / MX_I2C2_Init()
  ├─ MX_TIM1~12_Init()              // 所有定时器初始化
  ├─ MX_USART1~6_UART_Init()        // 所有串口初始化
  └─ Mymain()                       // ★ 用户主函数入口
       └─ Mode_G_Setup()            // 全局初始化
            ├─ Initial_ALL()
            │   ├─ OLED_Init()          // OLED 初始化
            │   ├─ RGB_Init()           // RGB LED
            │   ├─ Serial_Init()        // Serial1/2 DMA 接收启动
            │   ├─ Encoder_Init()       // EC11 EXTI 初始化
            │   ├─ Param_AT24C02_Init() // AT24C02 注册 + 上电恢复
            │   ├─ Stepper_Init()       // 步进电机初始化 + PID + 限位
            │   ├─ Flash_Mode_Init()    // LED 闪烁工具
            │   └─ Timer_Counter_Init() // DWT 计时工具
            ├─ Initial_Timer()
            │   └─ Timer_Initial()      // 启动 TIM6(1ms) + TIM7(20ms) 中断
            └─ 模式记忆恢复             // 从 AT24C02 恢复上次模式
       └─ while(1)                    // 主循环
            ├─ OLED_Clear()
            ├─ Mode_G_Loop()           // 按键检测 + 模式切换
            ├─ 模式调度:               // curr_mode==next_mode?Loop:Exit+Setup
            │   └─ curr_mode = next_mode
            │   └─ 模式记忆保存
            └─ OLED_Update()
```

### 13.2 关键时序

| 步骤 | 说明 |
|------|------|
| 1 | CubeMX 生成的 HAL 初始化（main.c 自动生成部分） |
| 2 | `Mymain()` 入口 |
| 3 | `Mode_G_Setup()` → `Initial_ALL()` 初始化所有业务模块 |
| 4 | `Initial_Timer()` **必须最后调用**，防止中断中访问未初始化的指针 |
| 5 | 从 AT24C02 恢复上次模式（如有效） |
| 6 | 进入主循环，开始模式调度 |

> **☆ 注意**: `Initial_Timer()` 必须放在 `Initial_ALL()` 之后。如果定时器先启动，中断回调可能访问尚未初始化的全局变量。

## 14. 配置指南

### 14.1 新增外设

1. **CubeMX 配置**: 在 `Template.ioc` 中配置引脚、外设
2. **重新生成 Core/**: 会自动更新 `Core/Inc/` 和 `Core/Src/`
3. **MySystem 映射**: 在 `MySystem.c` 中添加 GPIO/PWM 实例
4. **MySystem.h**: 如有需要，引入新的 HAL 头文件
5. **如果是新定时器**: 在 `MyTimer.c` 的 `HAL_TIM_PeriodElapsedCallback` 中添加判断

### 14.2 新增模式

1. 创建 `Mode/Mode_5.h` 和 `Mode/Mode_5.c`
2. 在 `Mode_G.h` 的 `Mode_Typedef` 枚举中，**在 `Mode_End` 之前**添加 `Mode_5`
3. 在 `AllHeader.h` 中 `#include "Mode_5.h"`
4. 在 `Top/Mymain.c` 的 switch-case 中添加对应分支
5. 在 `Mode/Mode_G.c` 的 `Timer_20ms_Callback` 中添加 `case 5: Mode_5_Tick(); break;`

### 14.3 新增 AT24C02 持久化参数

1. 在 `Mode/Mode_1.c` 的 `s_AT_Params[]` 数组**末尾**添加（**不能插入中间**）
2. 使用对应的注册宏：`AT_PARAM_I8/I16/I32/F`
3. 在 `Mode/Mode_1.c` 的 `Mode_1_Setup()` 中注册对应的 ParamEdit UI 参数
4. 如是首次添加，考虑先 `EraseAll()` + `PARAM_FORCE` 清空旧布局

### 14.4 CubeMX 重新生成后的注意事项

以下文件会被 CubeMX 覆盖，如做了手动修改需注意：

| 文件 | 手动修改内容 | 处理方式 |
|------|-------------|----------|
| `Core/Src/gpio.c` | EC11 引脚需 `GPIO_MODE_IT_FALLING` | 重新生成后手动改回 |
| `Core/Src/stm32f4xx_it.c` | TIM9/TIM12 中断处理函数 | 已写在 USER CODE 区间，不会被覆盖 |
| `Core/Src/main.c` | `#include "Mymain.h"` + `Mymain()` | 已写在 USER CODE 区间 |
| `Core/Inc/main.h` | 引脚宏定义 | 由 CubeMX 自动重新生成 |

### 14.5 调试串口配置

默认 **USART1 (Serial1)** 用于调试输出，**USART2 (Serial2)** 用于香橙派通信。

如需更换调试串口：
1. 修改 `Serial_porting.c` 中 `Serial1` 的绑定
2. 修改 `Mode_3.c` 中使用的串口实例

### 14.6 编译优化建议

| 场景 | 建议 |
|------|------|
| 调试阶段 | `-O0`，查看反汇编 |
| 发布版本 | `-Og` 或 `-O1`，保持调试信息 |
| 性能关键 | `-O2`，注意 volatile 变量 |

## 15. 失能/关闭功能指南

| 目标 | 操作 |
|------|------|
| 关闭某个 Mode | `Top/Mymain.c` 中对应 case 改为 `break;` |
| 关闭模式记忆（上电不恢复） | `Top/Mymain.c` 注释掉 `Param_AT24C02_Write(&curr_mode)` |
| 关闭 AT24C02 整系统 | `Top/AllHeader.c` 注释掉 `Param_AT24C02_Init()` |
| 关闭 ParamEdit UI | `Mode_1_Loop()` 注释掉 `Param_Loop()` |
| 关闭 PARAM_FORCE | 确保 `Mode_G.c` 中所有 PARAM_FORCE 行已注释 |
| 关闭 Serial2 | `Serial_porting.h` 注释掉 `#define Serial2_Enable 1` |
| 关闭步进电机 | `Top/AllHeader.c` 注释掉 `Stepper_Init()` 和 `Con_Stepper.h` 引用 |
| 关闭位置模式 | 不调用 `Stepper_PWM_Pos_Set_Abs/Rel`，仅用速度模式 |

## 附录 B: 代码约定与注意事项

| 规则 | 说明 |
|------|------|
| **Task 库弃用** | 已弃用 `Task.h`，使用静态计数器在 20ms/1ms Tick 中实现周期任务 |
| **KEY_0 占用** | KEY_0 被 Mode_G 占用（单击=LED快闪，双击=换模式），测试只用 KEY_1/KEY_2/KEY_3 |
| **OLED_Update** | Mymain 末尾统一调用，各 Mode/Layer 不再调用 OLED_Update() |
| **测试代码** | 放 Mode_2，简洁为主，写清测试流程和预期现象 |
| **模式记忆** | 切模式自动保存到 AT24C02，下次上电自动恢复。Mode_Null 不保存 |
| **PARAM_FORCE** | 手动推送默认值用，推送完必须重新注释 |
| **AT 参数表顺序** | `s_AT_Params[]` 数组顺序一旦确定不可改，增删只能加末尾 |
| **类型匹配** | `AT_PARAM_xx` 字节数必须和变量 sizeof 一致（如 I8 配 int8_t），否则内存越界 |
| **定时器初始化顺序** | `Initial_Timer()` 必须最后调用，防止中断提前访问未初始化指针 |
| **CubeMX 再生** | EC11 引脚需手动设回 `GPIO_MODE_IT_FALLING` |
| **EC11 编码器** | 进入编辑模式前先 `Encoder_Get()` 丢弃积攒值，避免参数跳变 |
