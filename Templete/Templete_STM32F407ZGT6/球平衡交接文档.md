## 1. 系统架构

```
摄像头(Orange Pi)                  IMU(MPU6050)
    │ USART2                         │ I2C1
    ▼                                ▼
Oran_Update() [10ms]           IMU_Get_Ax() [20ms]
    │ Oran_real (球位置)             │ 前后加速度(g)
    │ Oran_Speed (球速度)            ▼
    ▼                          低通滤波 (α=0.3)
Oran_PID_Update() [20ms]           │
    │                               ▼
    ├─ 位置PID (Kp/Ki/Kd)    ff_angle = ax × 22 / 0.038
    │                               │
    └──────────────┬────────────────┘
                   ▼
    Stepper_Set_Angle(Stepper1, ff_angle - PID.setPoint)
                   │
                   ▼
    内环角度PID [1ms] → 步进电机 → 板倾斜 → 球滚动
```

## 3. 各模式功能

### Mode_4 — 寻迹+球平衡联调

- KEY1: 启动(寻迹+球平衡同时运行)
- KEY2 ±10: 调巡航速度
- IDLE 时球平衡也在跑(Oran_PID_Update)，可预先看球是否稳住
- 检测到终点(Y8U停止线+偏航>330°) → 立即停车
- 速度参数: `Mode4_Tar_Speed`(默认70rpm)、`Ramp_Up_Cnt`(5)、`Ramp_Dn_Cnt`(3)
- PRE_DECEL 触发角: 300°

### Mode_5 — 球速PID调参

- OLED 显示 Kp/Ki/Kd/球速/PID输出
- 串口 ABC 调参: `@Kp=` `@Ki=` `@Kd=` `@Goal=`
- CSV(20ms): Goal, Real, Set, Pout, Iout, Dout
- 当前初始值: Kp=0.08, Kd=0.5, Ki=0

### Con_Mode_3 — 球位置PID (Q3)

- 位置环 PID(Oran_PID_Update), goal恒=0, 偏移通过 Oran_Real_Offset 模拟
- KEY1: 启动阶跃+斜坡测试(O→+195→-195)
- KEY2: 重置PID
- CSV(20ms): Goal, Real, Set, Y8U_Speed, Yaw, ff_angle

## 4. 串口 ABC 调参命令 (Serial1, @...$# 格式)

### 位置环 (Con_Mode_3 / Mode_4)

| 命令 | 参数 | 说明 |
|------|------|------|
| `@Kp=0.16$#` | PID_Oran.Kp | 位置环比例 |
| `@Ki=0.013$#` | PID_Oran.Ki | 位置环积分 |
| `@Kd=5.0$#` | PID_Oran.Kd | 位置环微分 |
| `@Goal=0$#` | Oran_Real_Offset | 目标位置偏移(px) |

### 前馈 (任意模式, 需在ABC处理中注册)

| 命令 | 参数 | 说明 |
|------|------|------|
| `@FFa=0.3$#` | Oran_FF_Alpha | 低通系数 |
| `@Len=22$#` | Oran_FF_Len | 板长 cm |
| `@Lift=0.038$#` | Oran_FF_Lift | 步进每度升降 cm/° |

### 速度环 (Mode_5)

| 命令 | 参数 | 说明 |
|------|------|------|
| `@Kp=0.08$#` | PID_Oran_Speed.Kp | 速度环比例 |
| `@Ki=0$#` | PID_Oran_Speed.Ki | 速度环积分(默认0) |
| `@Kd=0.5$#` | PID_Oran_Speed.Kd | 速度环微分 |
| `@Goal=0$#` | PID_Oran_Speed.goalPoint | 目标球速(px/s) |
| `@Alp=0.3$#` | Oran_Speed_Filt_Alpha | 球速低通滤波(0=无滤波, 0.3=默认) |
| `@Df=0.3$#` | PID_Oran_Speed.d_filter | D项低通滤波(抑制微分噪声) |

## 5. 机械参数

| 参数 | 值 | 含义 |
|------|-----|------|
| 板长度 | 22 cm | 铰链到步进支撑点 |
| 步进升降比 | 0.038 cm/° | 步进转1° → 前端升降0.038cm |
| 像素标定 | 39 px/cm | Oran_Single_Pos=39≈1cm |
| ±5cm | ±195 px | 比赛Q3要求 |
| IMU前进轴 | IMU_Get_Ax() | 前后加速度, 前=正 |

## 6. 已知问题和待解决

2. **速度环已改进**: 2026-08-01 增加 Kd=0.5 初始值、球速 LPF(Alp)、D项 LPF(Df)、微分先行。参数均可在线调，待实际烧录测试最优值
3. **前馈未加ABC入口**: Oran_FF_Alpha/Len/Lift 在 Mode_4/Con_Mode_3 的 Loop 中没有注册 ABC 命令
4. **参数未持久化**: PID 和前馈参数断电丢失, 需注册到 AT24C02
5. **Con_Mode_4/5/6**: 空壳, 待实现完整比赛逻辑
