# MPU6050需求说明书

## 1. 基础物理量

| 传感器   | 输出轴向     | 单位            | 说明                         |
| -------- | ------------ | --------------- | ---------------------------- |
| 加速度计 | `Ax, Ay, Az` | g（重力加速度） | 反映“静止方向”或“运动加速度” |
| 陀螺仪   | `Gx, Gy, Gz` | °/s（角速度）   | 表示“旋转速度”               |



## 2. 参考内容:

* 从原始数据到“有意义的物理量”,原始数据都是 **16位ADC值（-32768～32767）**，需要转换成实际单位。

* 得到姿态角(必须结合融合算法)

### 常用数据融合算法（由简单到精确,AI生成）

| 算法                                 | 原理简述                           | 精度 | 难度             |
| ------------------------------------ | ---------------------------------- | ---- | ---------------- |
| **互补滤波 (Complementary Filter)**  | 高通滤波陀螺仪、低通滤波加速度     | ⭐⭐   | 简单快速         |
| **卡尔曼滤波 (Kalman Filter)**       | 统计滤波，利用噪声模型优化状态估计 | ⭐⭐⭐⭐ | 精确但计算量大   |
| **Madgwick / Mahony 滤波**           | 专为姿态融合设计的高效算法         | ⭐⭐⭐⭐ | 性能好，适合MCU  |
| **DMP（MPU6050自带数字运动处理器）** | 芯片内部自动融合并输出姿态角       | ⭐⭐⭐⭐ | 省算力但配置复杂 |

* 其他参考资料

### DMP（数字运动处理器）

MPU6050 内部其实有一个 “DMP” 协处理器，可以自动帮你融合陀螺仪和加速度数据，输出：

```
四元数（Quaternion）
欧拉角（Pitch / Roll / Yaw）
```

但要使用 DMP，需要：

- 加载官方 DMP 固件到 MPU6050；
- 使用开源库（如` Jeff Rowberg` 的 MPU6050 库）；
- 通过 I2C 读取融合后的数据。



## 3. 总结与建议

* AI生成

| 阶段   | 建议操作                                 | 说明             |
| ------ | ---------------------------------------- | ---------------- |
| 🥇 入门 | 读取原始加速度和陀螺仪数据，完成单位换算 | 理解基础输出     |
| 🥈 进阶 | 计算 Pitch、Roll（静态）                 | 用加速度法       |
| 🥉 提升 | 加入互补滤波                             | 实现平滑动态姿态 |
| 🏆 高级 | 使用 `Madgwick` 或 DMP 输出欧拉角/四元数 | 精确稳定         |
