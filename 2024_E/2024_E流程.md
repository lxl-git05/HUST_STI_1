## 1. 题目1 

+ 按下串口屏的题目1，进入题目1，==串口屏发送指令：STM32主板进入Con_Mode_1==
+ 串口屏
  + 选择任意一颗黑色棋子
  + 按到5号棋子
  + 串口屏发送指令：==STM32与视觉进行通信，实现棋子放在5号棋盘==
    + 格式：【Move=棋号(1-5)、棋种类(0黑1白)，放置位置(1-9)】
    + STM32知道是哪一颗棋子
  + 完成放置
    + 串口屏发送指令：==STM32归位棋子==

|    LCD发送    | STM32发送 |            效果             |
| :-----------: | :-------: | :-------------------------: |
| @Con_Mode_1$# |           |       STM32进入题目1        |
| @Move=%d05$#  |           | STM32知道需要移动哪一颗黑棋 |
|   @Reset$#    |           |       STM32将黑棋归位       |

## 2. 题目2

+ 按下串口屏的题目2，进入题目2，==串口屏发送指令：STM32主板进入Con_Mode_2==

+ 串口屏
  + 选择2个黑棋2个白棋
  + ==每次放在棋盘上就会触发发送指令功能==
    + 发送 【Move=棋号(1-5)、棋种类(0黑1白)，放置位置(1-9)】，比如"@Move=209$#"
      + 将黑色2号棋放在9号棋盘位置
  + 进行确认，==允许STM32出发==
  + STM32开始进行移动
+ STM32
  + ==每次移动完成一个棋子，就要求LCD进行更新：【棋码号 颜色号】==

+ 串口屏
  + ==按下复位，要求STM32进行复位==
+ STM32
  + ==复位的时候发送LCD清空单个棋盘指令==



|    LCD发送     |       STM32发送       |              效果               |
| :------------: | :-------------------: | :-----------------------------: |
| @Con_Mode_2$#  |                       |       要求STM32进入题目2        |

# 3. 流程详细步骤

前提：

1. 装置在起点
2. LCD在菜单选择界面

## 3-1 题目1

+ 首先进入LCD菜单
+ 进入题目1(LCD->**@Con_Mode_1$#**->STM32->**@Con_Mode_1:1$#**->Orange)
  + 选择一个黑棋子
  + 放在井字中间位置（LCD->**@Move=%d$#**->STM32->**@Move:%d$#**->Orange）

+ 接下来Orange开始接管STM32下位机
  + (Orange->**@TarXY$#**->STM32，STM32接到命令，开始执行xy寻迹指令，完成之后返回**@OK:4$#**)
  + (Orange->**@Down$#**->STM32，STM32接到命令，开始执行取/放棋任务，完成之后返回**@OK:5$#**)
    + 本命令在本题应该至少执行两次（取+放）
  + (Orange->**@Back$#**->STM32，STM32接到命令，回家，完成之后返回**@OK:6$#**)



## 3-2 题目2

+ ==注意：现在开始指令不再带帧头帧尾（纯属懒得打字，但是代码还是有实现）==

+ 首先进入LCD菜单
+ 进入题目2(LCD->**@Con_Mode_2$#**->STM32->**@Con_Mode_2:2$#**->Orange)
  + 选择两个黑棋子和两个白棋子并且放入棋盘
    + 每次放入棋盘的时候，(LCD->**Move=%d-**>STM32->**Move:%d**->Orange)(注:香橙派记得记录四个位置)
+ 接下来Orange开始接管STM32下位机，<u>流程基本一样，只是STM32在完成Down之后，orange会继续下一次TarXY</u>
  + (Orange->**@TarXY$#**->STM32，STM32接到命令，开始执行xy寻迹指令，完成之后返回**@OK:4$#**)
  + (Orange->**@Down$#**->STM32，STM32接到命令，开始执行取/放棋任务，完成之后返回**@OK:5$#**)
    + 本命令在本题应该至少执行两次（取+放）
  + (Orange->**@Back$#**->STM32，STM32接到命令，回家，完成之后返回**@OK:6$#**)

## 3-4 题目4

+ 首先进入LCD菜单
+ 进入题目4(LCD->**@Con_Mode_4$#**->STM32->**@Con_Mode_4:4$#**->Orange)
  + 装置先下第一颗黑棋，所以人现在需要在LCD帮装置下一个黑棋
    + (LCD->**Move=%d-**>STM32->**Move:%d**->Orange)
+ 接下来Orange接管STM32
  + 先把刚刚要求的黑棋下了
    + 老样子，TarXY然后Down然后TarXY然后Down然后Back
  + 人手放一个白棋
    + (Orange->**Update=%d**->STM32->LCD，STM32因此更新LCD的棋盘)
  + Orange要求下一个黑棋
    + 老样子，TarXY然后Down然后TarXY然后Down然后Back，Back完成之后记得更新棋盘：(Orange->**Update=%d**->STM32），然后没事了，等待人下白棋
  + 循环往复。。。。。。
+ 获胜即结束
