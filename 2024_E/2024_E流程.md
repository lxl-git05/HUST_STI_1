# 流程

+ 串口屏显示题目1-6的编号，可以进行选择
  + 进入任何一道题目，按下按键可以返回主菜单
  + 题目各自设计界面

## 1. 题目1 

+ 按下串口屏的题目1，进入题目1，==串口屏发送指令：STM32主板进入Con_Mode_1==
+ 串口屏
  + 选择任意一颗黑色棋子
  + 按到5号棋子
  + 串口屏发送指令：==STM32与视觉进行通信，实现棋子放在5号棋盘==
    + 格式：【Move=棋号(1-5)、棋种类(0黑1白)，放置位置(1-9)】
    + STM32知道是哪一颗棋子
  + 完成放置
    + 串口屏发送指令：==STM32归位棋子==

|    LCD发送    | STM32发送 |            效果             |
| :-----------: | :-------: | :-------------------------: |
| @Con_Mode_1$# |           |       STM32进入题目1        |
| @Move=%d05$#  |           | STM32知道需要移动哪一颗黑棋 |
|   @Reset$#    |           |       STM32将黑棋归位       |

## 2. 题目2

+ 按下串口屏的题目2，进入题目2，==串口屏发送指令：STM32主板进入Con_Mode_2==

+ 串口屏
  + 选择2个黑棋2个白棋
  + ==每次放在棋盘上就会触发发送指令功能==
    + 发送 【Move=棋号(1-5)、棋种类(0黑1白)，放置位置(1-9)】，比如"@Move=209$#"
      + 将黑色2号棋放在9号棋盘位置
  + 进行确认，==允许STM32出发==
  + STM32开始进行移动
+ STM32
  + ==每次移动完成一个棋子，就要求LCD进行更新：【棋码号 颜色号】==

+ 串口屏
  + ==按下复位，要求STM32进行复位==
+ STM32
  + ==复位的时候发送LCD清空单个棋盘指令==



|    LCD发送     |       STM32发送       |              效果               |
| :------------: | :-------------------: | :-----------------------------: |
| @Con_Mode_2$#  |                       |       要求STM32进入题目2        |
| @Move=%d%d%d$# |                       | 要求STM32移动Type号棋到特定位置 |
|   @Enable$#    |                       |      STM32接收完毕开始工作      |
|                | LCD的对应棋码颜色更新 |                                 |
|    @Reset$#    |                       |       要求STM32将黑棋归位       |
|                | LCD的对应棋码颜色更新 |                                 |
